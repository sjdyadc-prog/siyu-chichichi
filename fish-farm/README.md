# 养鱼高手思宇

手机优先的原创像素养鱼经营游戏。购买鱼苗、喂养成鱼、加工鱼肉并售卖，或保留同种成鱼繁育。逐步升级自动运输、投喂、加工与育苗设施，收集 80 种鱼（60 种河湖/海洋鱼与 20 种奇想鱼）。楠楠鱼是最高价典藏鱼。

## 操作

- 轻点鱼：查看详情、留种或加工。
- 拖成熟鱼到加工台：排队加工；鱼肉完成后点击售卖。
- 拖成鱼到育苗房：留种保护，两条同种成鱼可繁殖。
- 自动传送带保护留种鱼，并自动加工、售卖其余成鱼。
- 在「设施」页可单独暂停传送带或投喂机；准备新亲鱼时先暂停传送带，选好留种鱼再开启。
- 图鉴支持名称搜索、类别和稀有度筛选。
- 自动保存到当前浏览器；支持 JSON 导入/导出和最多两小时离线模拟。

## 运行

直接打开 index.html，或用任意静态 HTTP 服务运行整个目录。在 HTTPS 下提供 PWA 缓存，支持兼容 Android 浏览器添加到主屏幕。没有远程账号、广告或支付。

## 来源与许可

研究了 MIT 项目 [Fishtank](https://github.com/dofy/fishtank) 的养鱼繁育机制，以及 [ChickenClicker](https://github.com/KokanP/ChickenClicker) 的放置升级思路。它们没有包含本作的养殖加工闭环，因此本作的程序、数值与全部像素绘图独立实现，没有复制这两个项目的代码或素材。

本目录代码与程序化像素图形采用 MIT 许可，参见 LICENSE。鱼类属性为休闲游戏数值，并非真实养殖资料。

## 验证范围

2026-11-06：完成 15 组经营逻辑回归，以及存档导入、92 条满塘和两小时离线结算检查；验证 80 个独立鱼种与 20 种奇想鱼、楠楠鱼的最高定价。像素素材使用真实 Canvas 渲染检查。手机布局按竖屏与触控设计，按钮至少 44 像素。

本次 Edge 自动化因工具无法可靠识别当前网址而中止，因此没有把手机真机操作、浏览器帧率或安装体验标记为已验收。具体流畅度还需在目标手机上确认。
